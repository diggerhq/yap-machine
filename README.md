# Yap machine

Finds the X posts worth answering. An [OpenComputer](https://opencomputer.dev)
agent runs every five minutes, pulls fresh posts through a handful of saved
X searches, and scores each against a private brief. A small app shows the
ranked feed; every post links to X, where you read the thread and reply by
hand. Nothing in it writes or posts for you.

Work in progress. This README is written once the build is verified.
